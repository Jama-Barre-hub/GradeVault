{% translate "Automatic calculations" %}

{% blocktranslate %}A teacher types 32 out of 40 and 51 out of 60. The total, percentage, letter grade, term average and class position follow on their own, so nobody adds up a column by hand and nobody makes the arithmetic mistake that changes a child's standing.{% endblocktranslate %}

{% translate "Private student access" %}

{% blocktranslate %}A student signs in with their own student number and sees their results only. Their page carries no way to name another student, so there is nothing to change in order to try.{% endblocktranslate %}

{% translate "Permanent grade history" %}

{% blocktranslate %}Every change records who made it, when, and what the mark was before. Nothing in the system can edit or delete that record: not a teacher, not a head teacher, not whoever runs the server.{% endblocktranslate %}

{% translate "Results released on your say-so" %}

{% blocktranslate %}Teachers enter and correct marks freely. Students see nothing until an administrator publishes the term, so no child learns their result the moment a teacher happens to save a page.{% endblocktranslate %}

{% translate "Mobile friendly" %}

{% blocktranslate %}Pages are small and plain, with nothing to download and nothing that needs a fast connection. A parent on a phone sees the same thing as a head teacher at a desk.{% endblocktranslate %}

{% translate "Built for Somali schools" %}

{% blocktranslate %}Two terms from September to June. Class names your school actually uses, whether that is Class 5 or Form 2. A grading scale with boundaries each school sets for itself.{% endblocktranslate %}

{% translate "How it works" %}

{% blocktranslate %}Three steps, from an empty system to a report card in a parent's hand.{% endblocktranslate %}

  1. 1

    {% translate "The school sets itself up" %}

    {% blocktranslate %}An administrator enters the year, its two terms, the classes, the subjects and the school's own grading scale.{% endblocktranslate %}

  2. 2

    {% translate "Teachers record marks" %}

    {% blocktranslate %}Each teacher sees only the classes and subjects they were given, and fills in a mark sheet. A mark higher than the paper is out of is refused before it can be saved.{% endblocktranslate %}

  3. 3

    {% translate "The school publishes the term" %}

    {% blocktranslate %}Results appear for students, who can read their subjects, grades, average and position, and print a report card to take home.{% endblocktranslate %}

{% translate "Keeping children's records safe" %}

{% blocktranslate %}These are records about children, so the plain answers matter more than the promises.{% endblocktranslate %}

{% translate "Can a teacher see another class's marks?" %}
{% blocktranslate %}No. A teacher reaches only the subjects and classes they were assigned, and this is refused whether they open the page or send the form directly.{% endblocktranslate %}
{% translate "Can a student see a classmate's results?" %}
{% blocktranslate %}No. A student's own page carries no way to name another student, so there is nothing to change in order to try.{% endblocktranslate %}
{% translate "Can a grade be changed quietly?" %}
{% blocktranslate %}No. Every change writes a record that nothing in the system is able to edit or remove.{% endblocktranslate %}
{% translate "Are passwords readable by staff?" %}
{% blocktranslate %}No. Passwords are stored scrambled in a way that cannot be reversed. An administrator can set a new one; nobody can read the old one.{% endblocktranslate %}
{% translate "Can someone guess a student's password?" %}
{% blocktranslate %}Ten wrong attempts pause sign-in for that account on that device for twenty minutes. One student being paused never affects their classmates, even on a shared school connection.{% endblocktranslate %}

{% blocktranslate %}One thing said plainly: GradeVault has not yet been examined by security specialists from outside the project. Before any school entrusts it with real records, it should be.{% endblocktranslate %}
