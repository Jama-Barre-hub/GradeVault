{% translate "What it does" %}

{% blocktranslate %}Replaces the paper register and the spreadsheet on one teacher's laptop.{% endblocktranslate %}

{% translate "Marks become results on their own" %}

{% blocktranslate %}A teacher types 32 out of 40 and 51 out of 60. GradeVault works out the total, the percentage, the letter grade, the term average and the position in class. Nobody adds up a column by hand, so nobody makes an arithmetic mistake that changes a child's standing.{% endblocktranslate %}

{% translate "Every change is recorded" %}

{% blocktranslate %}When a mark changes, GradeVault records who changed it, when, and what it was before. Nothing can edit or delete that record — not a teacher, not a head teacher, not the person running the system. A school can prove a grade is the one its teacher entered.{% endblocktranslate %}

{% translate "Results appear when the school says so" %}

{% blocktranslate %}Teachers enter and correct marks freely. Students see nothing until an administrator publishes the term. No child learns their result the moment a teacher happens to save a page.{% endblocktranslate %}

{% translate "Each school is separate" %}

{% blocktranslate %}Many schools can use one installation, and none of them can see another's students, marks or staff. This is checked by tests that deliberately try to reach another school's records and must fail.{% endblocktranslate %}

{% translate "Report cards that print" %}

{% blocktranslate %}One student, one term, on one page: subjects, marks, grades, position, and space for the class teacher, head teacher and parent to sign. It prints as a document, not as a web page with menus down the side.{% endblocktranslate %}

{% translate "Built for the connection you have" %}

{% blocktranslate %}Pages are small and plain, with no app to download and nothing that needs a fast connection. A parent on a phone in Mogadishu sees the same thing as a head teacher at a desk.{% endblocktranslate %}

{% translate "How it works" %}

  1. 1

    {% translate "The school sets itself up" %}

    {% blocktranslate %}An administrator enters the year, its two terms, the classes, the subjects and the school's own grading scale. Class names are whatever the school uses — Class 5, Form 2, or anything else.{% endblocktranslate %}

  2. 2

    {% translate "Teachers record marks" %}

    {% blocktranslate %}Each teacher sees only the classes and subjects they were given, and fills in a mark sheet for them. A mark higher than the paper is out of is refused before it can be saved.{% endblocktranslate %}

  3. 3

    {% translate "The school publishes the term" %}

    {% blocktranslate %}When the results are ready, an administrator releases them. Students sign in with their own student number and see their subjects, grades, average and position, and can print a report card.{% endblocktranslate %}

{% translate "Keeping children's records safe" %}

{% blocktranslate %}These are records about children, so the plain answers matter more than the promises.{% endblocktranslate %}

{% translate "Can a teacher see another class's marks?" %}
{% blocktranslate %}No. A teacher reaches only the subjects and classes they were assigned, and this is refused whether they open the page or send the form directly.{% endblocktranslate %}
{% translate "Can a student see a classmate's results?" %}
{% blocktranslate %}No. A student's own page carries no way to name another student, so there is nothing to change in order to try.{% endblocktranslate %}
{% translate "Can a grade be changed quietly?" %}
{% blocktranslate %}No. Every change writes a record that nothing in the system is able to edit or remove.{% endblocktranslate %}
{% translate "Are passwords readable by staff?" %}
{% blocktranslate %}No. Passwords are stored scrambled in a way that cannot be reversed. An administrator can set a new one; nobody can read the old one.{% endblocktranslate %}
{% translate "Can someone guess a student's password?" %}
{% blocktranslate %}Repeated wrong attempts pause sign-in for that account and device. One student being locked out never locks out their classmates, even on a shared school connection.{% endblocktranslate %}

{% blocktranslate %}One thing said plainly: GradeVault has not yet been examined by security specialists from outside the project. Before any school entrusts it with real records, it should be.{% endblocktranslate %}
